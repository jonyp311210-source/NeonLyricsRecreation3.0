# SkyLyrics

Floating karaoke lyrics bar for Minecraft (Fabric 1.21.1).

## Features
- Floating dark karaoke bar (like Spotify)
- Word-by-word highlighting (Progressive or Whole line)
- Split Left/Right, position, height, fade previous lines
- Settings menu (press **J**)

## Build
```bash
./gradlew build
```
Jar will be in `build/libs/`

## Use
Press **J** in-game to open settings.
